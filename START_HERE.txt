LOCAL TEST
1. Open this folder in VS Code.
2. Open Terminal.
3. If this is a newly extracted folder, run:
   npm install
4. Start local development:
   npm run dev
5. Open:
   http://localhost:3000/

PRODUCTION BUILD (next step before hosting)
1. Stop the dev server with Ctrl+C.
2. Run:
   npm run build
3. Confirm a new "out" folder is created.
