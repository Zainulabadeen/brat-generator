# Pre-Live SEO Research & Migration Notes

## Public old-URL discovery
Public web searches for `site:bratgeneratorpro.net` and exact mentions of `bratgeneratorpro.net` returned no discoverable indexed URLs or external mentions at the time of this audit. This is useful, but it is **not a substitute** for Search Console, server logs, or a WordPress sitemap/backup. Therefore, the migration includes a safe starter redirect map for likely alternate slugs while preserving the final canonical URL structure.

## Competitive patterns observed
- Real-time browser rendering and no-sign-up/no-watermark positioning are common.
- Several competitors offer multiple output ratios and high-resolution export.
- Stronger competitors publish dedicated album-cover/tutorial pages rather than relying on one homepage.
- Some competitors have earned third-party visibility through editorial/tool-directory listings and founder/technical articles.

## Pre-live backlink / outreach opportunity map
Prepare these targets for outreach **after the new site is live and stable**:
1. SaaS/tool directories that already list Brat-generator products.
2. AI/tool discovery directories with editorial product pages.
3. DEV Community / ShowDev style technical write-ups about building a client-side canvas tool.
4. Design-tool comparison/resource pages.
5. Creator/marketing communities where a free no-sign-up visual tool is genuinely useful.

Do not buy bulk backlinks, use automated comment spam, or create fake reviews. The outreach angle should be the real tool, useful tutorials, privacy-first browser rendering, and original examples.
