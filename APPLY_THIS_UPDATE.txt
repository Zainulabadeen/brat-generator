BRAT GENERATOR — COMPACT TOOL HERO + FULL-SITE LANGUAGE UPDATE

Apply:
1. Extract this ZIP.
2. Copy all folders/files into the existing Brat Generator project root.

4. Run:
   npm run technical:check
   npm run build
   npm run dev
