BRAT GENERATOR — PERFORMANCE + LAYOUT UPDATE

1. Make a backup of your current working project folder.
2. Extract this ZIP.
3. Copy everything from the extracted folder into your current project folder.
4. Choose “Replace the files in the destination” when Windows asks.
5. In VS Code run: npm run dev
6. Check Home, Features, How to Use, Brat Styles, Video Generator and Blog.
7. Stop the dev server with Ctrl+C.
8. Run: npm run prelive
9. If PASS appears, push to GitHub:
   git add .
   git commit -m "Improve performance and unify page layout"
   git push
