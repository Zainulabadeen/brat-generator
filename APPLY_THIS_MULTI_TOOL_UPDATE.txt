IMPORTANT — GOOGLE LOGIN SETUP
The Login button needs YOUR Google OAuth client ID. Create a Web Application OAuth Client in Google Cloud.
Authorized JavaScript origins should include:
  http://localhost:3000
  https://bratgeneratorpro.net

Then create .env.local in your project root:
  NEXT_PUBLIC_GOOGLE_CLIENT_ID=YOUR_CLIENT_ID.apps.googleusercontent.com

Restart npm run dev after changing .env.local.
The current implementation is a client-side sign-in/profile display for this static site. Do not use it as a server-side authorization system for protected/private data without adding backend token verification.

IMPORTANT — LANGUAGE BEHAVIOUR
- Header/navigation labels use built-in translations for all included languages.
- Initial locale is selected from browser language, with timezone fallback for target markets.
- Full visible-page translation is attempted through the browser's built-in Translator API where supported.
- That browser Translator API is experimental and is not supported by every browser/device, so universal full-page automatic translation cannot be guaranteed without creating dedicated translated routes or using a translation service/API.
